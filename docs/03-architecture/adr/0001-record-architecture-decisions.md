# ADR-0001: Record architecture decisions

| Field | Value |
| --- | --- |
| Status | Accepted |
| Date | 2026-11-18 |
| Deciders | PQ-CA team |

## Context

Design decisions (algorithm choice, service boundaries, key storage, AI data boundaries) are spread across
the proposal, SRS, meeting notes and chat. The reasons behind them get lost, and later changes are hard to evaluate.

## Decision

Record every significant architecture decision as a Markdown ADR in this folder, using the
[ADR template](../../../templates/adr-template.md).

## Consequences

- New members and reviewers can see why the system looks the way it does.
- Decisions are reviewed through pull requests like any other document.
- Changing a decision requires a new ADR that supersedes the old one.
