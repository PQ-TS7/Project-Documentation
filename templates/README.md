# Templates

Copy a template, rename it in `kebab-case`, and fill it in.

| Template | Use for |
|---|---|
| [document-template.md](document-template.md) | Any formal document (spec, design, report) |
| [adr-template.md](adr-template.md) | Architecture Decision Records |
| [meeting-notes-template.md](meeting-notes-template.md) | Team, supervisor and Q&A meetings |
| [runbook-template.md](runbook-template.md) | Operational procedures |
| [component-template.md](component-template.md) | Microservice design docs in `05-components` |
